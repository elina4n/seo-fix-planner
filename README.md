# seo-fix-planner

Κώδικας για τη μεταπτυχιακή μου διπλωματική (MSc Digital Marketing, Πανεπιστήμιο Πατρών).

Τα εργαλεία τεχνικού SEO audit (Semrush, Screaming Frog κ.ά.) βγάζουν μια λίστα με
προβλήματα ταξινομημένα κατά σοβαρότητα. Στην πράξη όμως πολλά από αυτά έχουν κοινή
αιτία, και κάποιες διορθώσεις πρέπει να γίνουν πριν από άλλες. Εδώ δοκιμάζω αν η λίστα
του εργαλείου μπορεί να γίνει σειρά διορθώσεων για sites WordPress, ώστε να χρειάζεται
λιγότερη δουλειά για το ίδιο αποτέλεσμα.

Η δουλειά είναι σε εξέλιξη. Προς το παρόν το εργαλείο διαβάζει ένα export του Semrush
και ελέγχει ποιες διορθώσεις του καταλόγου καλύπτουν τα προβλήματα που βρέθηκαν.

## Εγκατάσταση

Στο τερματικό Git Bash του VS Code:

```
py -m venv .venv
source .venv/Scripts/activate
pip install -r requirements.txt
```

## Χρήση

Το export του Semrush μπαίνει στο `data/raw/`. Μετά:

```
python src/ingest.py data/raw/<export>.xlsx
python src/catalog_check.py
```

## Αρχεία

- `catalog/fixes.yaml`: οι διορθώσεις, τι λύνει η καθεμία, πόσο χρόνο θέλει και από τι εξαρτάται
- `catalog/severity_semrush.yaml`: η σοβαρότητα κάθε προβλήματος όπως τη δίνει το Semrush
- `catalog/config.yaml`: βάρη και ρυθμίσεις
- `src/`: ο κώδικας
- `docs/decisions.md`: σημειώσεις για τις αποφάσεις που πήρα και γιατί

Οι τιμές στα αρχεία του `catalog/` είναι προς το παρόν προσωρινές.
