# Σημειώσεις για τη Συζήτηση

Παρατηρήσεις που δεν είναι αποτελέσματα αλλά θα χρειαστούν στο κεφάλαιο της
Συζήτησης. Η πηγή κάθε παρατήρησης είναι στο αντίστοιχο αρχείο του
docs/verification/.

## Οι οδηγίες του εργαλείου

- **Αντιμετωπίζουν συμπτώματα.** Για τα 4xx και τα broken internal links το
  How to fix του Semrush λέει να αφαιρεθούν ή να αλλάξουν τα links. Εδώ οι
  σελίδες υπάρχουν και φταίνε οι κανόνες rewrite. Αν ακολουθούσα τις οδηγίες
  πρόβλημα-πρόβλημα, θα άλλαζα 18 σωστά links και θα έπρεπε να τα ξαναβάλω. (F01)
- **Είναι γενικές.** "Use a server that supports HSTS" (F03), "Review all
  broken JavaScript and CSS files ... and fix any issues" (broken JS/CSS).
- **Δεν λένε τις προϋποθέσεις.** Για το HSTS το RFC 6797 θέλει https και
  έγκυρο πιστοποιητικό, και προτείνει ανακατεύθυνση http → https. Το Semrush δεν
  τα αναφέρει. (F03)
- **Διαφωνούν με τη Google.** Το Semrush λέει ότι το μεγαλύτερο κείμενο
  κατατάσσεται ψηλότερα, η Google (Mueller) ότι ο αριθμός λέξεων δεν είναι
  παράγοντας. Το Semrush προτείνει llms.txt, η Google (Illyes) λέει ότι δεν το
  χρησιμοποιεί. (F05, F06)
- **Μερικές φορές λένε οι ίδιες ότι μπορεί να μην αξίζει.** "If this issue
  doesn't affect your page load time, simply ignore it." (F02)

## Τι δεν βλέπει το audit

- Τον server: nginx μπροστά από Apache. Από αυτό εξαρτάται αν μια διόρθωση
  γίνεται από το WordPress, από το .htaccess ή μόνο από τον πάροχο. (F01, F02)
- Την έκδοση της PHP (7.4, χωρίς υποστήριξη).
- Ότι το page cache έχει μόνο 2 αρχεία, άλλο ένα σύμπτωμα των 404. (F01)

## Είδη σχέσεων ανάμεσα σε διορθώσεις

- **Επικάλυψη:** μία διόρθωση λύνει πολλά προβλήματα (F01).
- **Αυστηρή εξάρτηση:** το HSTS λειτουργεί μόνο μέσω https (RFC 6797, MUST).
- **Χαλαρή εξάρτηση:** η ανακατεύθυνση http → https είναι προτεινόμενη
  (RFC 6797, SHOULD). (F03)
- **Εξάρτηση εύρους:** μετά την F01 το Semrush θα δει περισσότερες σελίδες και
  θα αλλάξει το εύρος άλλων διορθώσεων (F04: από μία σελίδα σε πολλές).
- **Κοινός πόρος:** F01 και F02 μπορεί να γράφουν στο ίδιο αρχείο (.htaccess).
- **Ομαδοποίηση που δεν στέκει πλήρως:** word count και text-to-HTML ratio
  διορθώνονται με διαφορετικό τρόπο. (F05)

## Πρακτικοί περιορισμοί

- Κοινός λογαριασμός cPanel του μαθήματος: ο χώρος δεν φτάνει για κλώνους.
- Δεν μπορεί να δοθεί πρόσβαση σε agent στο cPanel χωρίς κίνδυνο για τα άλλα sites.
