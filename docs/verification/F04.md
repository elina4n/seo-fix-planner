# F04: Meta description στην αρχική

Γράφτηκε: 10/11/2026, πριν από τη δοκιμή στον κλώνο.
Κατάσταση: hypothesis

## Η υπόθεση

Η αρχική σελίδα δεν έχει meta description. Αν γραφτεί από το SEO plugin, φεύγει
το πρόβλημα "Missing meta description".

## Η αλυσίδα

- **0.** Η σελίδα δεν έχει το στοιχείο meta description στο HTML.
- **1.** Το Semrush το καταγράφει ως "Missing meta description".
- **2.** Το SEO plugin προσθέτει το στοιχείο όταν συμπληρωθεί το πεδίο.

## Πηγές ανά κρίκο

- **Γιατί μετράει.** Google Search Central, "Control your snippets in search
  results": "Google sometimes uses the meta description HTML element if it might
  give users a more accurate description of the page" και "Create unique
  descriptions for each page on your site."
  https://developers.google.com/search/docs/appearance/snippet
- **1.** Semrush Site Audit, "Missing meta description" (About the issue):
  "Though meta descriptions don't have a direct influence on rankings, they are
  used by search engines to display your page's description in search results."
  και "If your page's meta description tag is missing, search engines will
  usually display its first sentence". How to fix: "you should ensure that all
  of your webpages have meta descriptions that contain relevant keywords."
  (πρόσβαση 10/11/2026)
  Το ίδιο το Semrush λέει ότι δεν επηρεάζει άμεσα την κατάταξη, άρα η αξία της
  διόρθωσης είναι στο click-through και όχι στο ranking. Και ζητάει description
  σε "all of your webpages", που στηρίζει ότι μετά την F01 το εύρος θα μεγαλώσει.

## Εξάρτηση από την F01

Τώρα το Semrush βλέπει μόνο 22 URLs, οπότε το πρόβλημα αφορά μία σελίδα. Όταν
ανοίξουν οι εσωτερικές σελίδες μετά την F01, πιθανότατα θα λείπει description
και από άλλες. Η διόρθωση θα γίνει από "μία σελίδα" σε "πολλές σελίδες" και ο
χρόνος θα αλλάξει. Παράδειγμα δουλειάς που αν γίνει πριν την F01 γίνεται με
μισή εικόνα.
