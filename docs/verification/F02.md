# F02: Browser caching για JavaScript και CSS

Γράφτηκε: 10/11/2026, πριν από τη δοκιμή στον κλώνο.
Κατάσταση: hypothesis

## Η υπόθεση

Ο server στέλνει τα αρχεία JavaScript και CSS χωρίς οδηγίες για το πόσο καιρό
να τα κρατάει ο browser (Cache-Control). Αν μπουν αυτές οι οδηγίες, μέσω plugin
cache ή του .htaccess, φεύγει το πρόβλημα "Uncached JavaScript and CSS files".

## Η αλυσίδα

- **0.** Ο server δεν στέλνει header Cache-Control (ή Expires) για τα .js και .css.
- **1.** Το Semrush το καταγράφει ως "Uncached JavaScript and CSS files".
- **2.** Ένα plugin cache ή κανόνες στο .htaccess προσθέτουν το header, και το
  πρόβλημα φεύγει.

## Πηγές ανά κρίκο

- **0, 2. Το caching ρυθμίζεται με το Cache-Control.** Chrome for Developers,
  Lighthouse, "Serve static assets with an efficient cache policy":
  "HTTP caching can speed up your page load time on repeat visits." και
  "Configure your server to return the Cache-Control HTTP response header".
  https://developer.chrome.com/docs/lighthouse/performance/uses-long-cache-ttl
- **1.** TODO: "About the issue" και "How to fix" του Semrush για το
  "Uncached JavaScript and CSS files".
- **Για το σχετικό πρόβλημα "Broken internal JavaScript and CSS files".**
  Semrush Site Audit (About the issue): "Any script that has stopped running on
  your website may jeopardize your rankings, since search engines will not be
  able to properly render and index your webpages." Κατηγορία: HTTP Status,
  Crawlability. How to fix: "Review all broken JavaScript and CSS files hosted
  on your website and fix any issues." (πρόσβαση 10/11/2026)
  Η κατηγορία "HTTP Status" δείχνει ότι τα αρχεία επιστρέφουν κωδικό σφάλματος,
  που στηρίζει την πιθανή σύνδεση με την F01. Το "How to fix" δεν λέει τι να
  κάνεις.

## Πιθανή εξάρτηση από την F01

Το Semrush βρίσκει και 16 "Broken internal JavaScript and CSS files". Αν κάποια
από τα ίδια αρχεία βγάζουν 404, τότε δεν έχει νόημα να μετρηθεί αν είναι
cached: πρώτα πρέπει να φορτώνουν. Αν ισχύει, η F02 εξαρτάται από την F01 και
το πραγματικό εύρος της φαίνεται μόνο μετά την F01.

## Εναλλακτικές εξηγήσεις

- Το caching υπάρχει, αλλά ο server το ακυρώνει για συγκεκριμένα αρχεία
  (π.χ. αρχεία από άλλο domain ή CDN). Ελέγχεται κοιτώντας τα headers ενός
  αρχείου στα Developer Tools του browser (Network).
