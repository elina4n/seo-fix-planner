# F03: HSTS

Γράφτηκε: 10/11/2026, πριν από τη δοκιμή στον κλώνο.
Κατάσταση: hypothesis

## Η υπόθεση

Ο server δεν στέλνει το header Strict-Transport-Security (HSTS). Αν προστεθεί,
φεύγει το πρόβλημα "No HSTS support". Το HSTS όμως λειτουργεί μόνο αν το site
είναι ήδη σε HTTPS και ανακατευθύνει το http στο https.

## Η αλυσίδα

- **0.** Το site πρέπει να ανοίγει παντού με https και το http να
  ανακατευθύνεται στο https.
- **1.** Ο server στέλνει το header Strict-Transport-Security στις απαντήσεις
  μέσω https.
- **2.** Το Semrush παύει να γράφει "No HSTS support".

## Πηγές ανά κρίκο

- **0–1. Το HSTS έχει νόημα μόνο μέσω https.** RFC 6797 (HTTP Strict Transport
  Security), ενότητα 7.2:
  "An HSTS Host MUST NOT include the STS header field in HTTP responses
  conveyed over non-secure transport."
  Και για την ανακατεύθυνση: "If an HSTS Host receives an HTTP request message
  over a non-secure transport, it SHOULD send an HTTP response message
  containing a status code indicating a permanent redirect, such as status
  code 301".
  https://www.rfc-editor.org/rfc/rfc6797
  Το RFC εξηγεί ότι η ανακατεύθυνση είναι "SHOULD" και όχι "MUST" λόγω κινδύνων
  και ιδιαιτεροτήτων κάθε site. Άρα: το header μέσω https είναι υποχρεωτικό
  (αυστηρή εξάρτηση), η ανακατεύθυνση http → https είναι έντονα προτεινόμενη
  (χαλαρή εξάρτηση).
  Ενότητα 8.1, από την πλευρά του browser: "If an HTTP response is received
  over insecure transport, the UA MUST ignore any present STS header field(s)."
  Και το header λαμβάνεται υπόψη μόνο αν "there are no underlying secure
  transport errors or warnings", δηλαδή χρειάζεται έγκυρο πιστοποιητικό SSL.
- **2.** Semrush Site Audit, "No HSTS support" (About the issue): "HTTP Strict
  Transport Security (HSTS) informs web browsers that they can communicate with
  servers only through HTTPS connections." How to fix: "Use a server that
  supports HSTS." (πρόσβαση 10/11/2026)
  Το "How to fix" δεν αναφέρει ούτε την ανακατεύθυνση http → https ούτε το
  πιστοποιητικό, δηλαδή τις προϋποθέσεις που βάζει το RFC.

## Κίνδυνος

Με την επιλογή includeSubDomains, ο browser θα ζητάει https και για όλα τα
subdomains. Ο λογαριασμός είναι κοινός με άλλα sites, οπότε το HSTS μπαίνει
χωρίς includeSubDomains και με μικρό max-age στη δοκιμή.

Αν κάτι πάει στραβά, η διόρθωση αναιρείται με max-age=0. RFC 6797, ενότητα 8.1:
"If the max-age header field value token has a value of zero, the UA MUST
remove its cached HSTS Policy information".
